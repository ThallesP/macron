Macron is installed: the program is /usr/local/bin/macron and its Windows runtime is in ~/Library/Application Support/Macron.

If Steam was open during the install, Macron could not register itself with Steam. Quit Steam, then run macron steam enable in Terminal. /Library/Logs/Macron-install.log says what the install did.

To remove Macron, run sudo macron-uninstall in Terminal with Steam closed.
