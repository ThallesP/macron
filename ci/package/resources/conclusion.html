Macron is installed: the program is /usr/local/bin/macron and its Windows runtime is in ~/Library/Application Support/Macron.

Open Steam: Windows-only games now have a working Install button, and Play starts them through Macron. If Steam was open, the installer closed it and opened it again.

/Library/Logs/Macron-install.log says what the install did. If it says Steam Play is not on, quit Steam and run macron steam enable in Terminal.

To remove Macron and put Steam back exactly as it was, run sudo macron-uninstall in Terminal.
